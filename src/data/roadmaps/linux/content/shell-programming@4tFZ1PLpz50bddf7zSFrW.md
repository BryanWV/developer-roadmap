# Shell Programming

Shell programming (scripting) automates administrative tasks, repetitive operations, and system monitoring in Linux. Bash is the default shell and scripting language in most distributions. Scripts are text files executed by the shell, excellent for system automation, for example: 

```bash
{
  "firstName": "John",
  "lastName": "Smith",
  "age": 25
}
```

The previous snippet creates a simple script that prints output to terminal.

Besides, you can make your script more dynamic by accepting input requests, and using all of the command-tools you've learned so far (like echo, ls, mkdir, grep, rm, less and many others)
